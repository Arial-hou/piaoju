# 漂居 · 短租青年的租房生活消费助手

在线使用：<https://arial-hou.github.io/piaoju/>

适合短租、经常搬家的年轻人。帮你算清楚"这件东西买了，住完卖掉加上搬家，实际要花多少钱"。

## 功能

| 页面 | 作用 |
| --- | --- |
| 入住清单 `#/recommend` | 按租期、预算、房型、生活习惯推荐必买和可选的物品，算出月均实际花费，可以存成图片 |
| 买还是租 `#/buy-or-rent` | 对比买了再转卖和租用两种方式的总成本 |
| 转卖文案 `#/moving` | 估算二手价，生成闲鱼风格的转卖文案 |
| 我的物品 `#/inventory` | 记录买过的东西，可以标记已卖出 |
| 退租清算 `#/settle` | 退租时逐件判断该卖还是该带走 |
| 退租倒计时 `#/lease` | 按入住和退租日期提醒各个时间节点 |
| 验房清单 `#/inspect` | 入住和退租时逐项检查 |
| 搬家估算 `#/move-cost` | 按东西多少和距离估算搬家费用 |
| 价格与数据 `#/settings` | 修改估算价、导出备份、清空数据 |

数据只保存在本机浏览器（localStorage），不会上传。

## 计算口径

- 实际花费 = 买入价 − 退租时转卖回收 + 搬家成本
- 转卖估价 = 新品价 × 成色 × 时间折旧（最低保留 30%）× 0.7（二手议价系数）
- 搬家成本：轻 ¥0 / 中 ¥40 / 重 ¥150 每件

## 价格来源（重要）

**所有价格默认都是人工估算值**，参考了主流电商入门款的新品价和二手平台常见的挂牌价，**不是实时成交价**。

价格的取用顺序为：内置估算 → `data/prices.json` → 用户在"价格与数据"页自己改的价格（优先级最高）。

自动更新新品价（可选）：
1. 在仓库 Settings → Secrets → Actions 里添加 `JD_APP_KEY` 和 `JD_APP_SECRET`（京东联盟开放平台的密钥）。
2. `.github/workflows/update-prices.yml` 每月 1 日会自动运行，也可以手动触发。
3. 没配置密钥或者接口失败时会自动跳过，保留原来的估算值。

本项目不会爬取闲鱼等平台的数据。

## 开发

```
index.html          页面外壳（底部导航）
js/data.js          物品库和默认价格
js/checklists.js    验房、搬家、退租时间节点
js/store.js         本地存储和价格合并
js/engine.js        计算逻辑
js/ui.js            通用组件
js/pages-*.js       各页面
js/handlers.js      交互事件
js/app.js           路由和初始化
src/input.css       样式源文件 → css/app.css（编译产物，需要提交）
```

修改样式或类名后需要重新编译：

```
npx tailwindcss@3 -i src/input.css -o css/app.css --minify
```

冒烟测试：`node audit/smoke.js`
